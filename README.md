# Aplikacija za praćenje sesije utrke
Ova aplikacija omogućuje praćenje sesije protekle utrke

## Brojevi
Svaki vozač je označen svojim trkačim brojem

## Gap
Ispod svakog vozača piše njegov razmak u sekundama ili krugovima od prvog vozača

## Deskripcija
U deskripciji se nalazi broj vozača, broj krugova te broj postignutih bodova

## Pokretanje
Pokrenite naredbom 'flutter run' u terminalu
